# IC293 curation — manual review decisions

Human review verdicts during IC293 single-cell curation, complementing the
automatic per-recording `curation_log.json`. Kept for method reporting.

| recording | reviewed | verdict | action / outcome |
|---|---|---|---|
| Pos20_cell3-KO | 2026-06-17 | **id1** is the target cell (present every frame, ~2000 µm²); **id2, id3, id4** are debris/artifacts | Matches corrected auto-curation. Exposed + fixed a bug: expected-cell-area was the *median* of persistent objects, which collapsed when persistent debris outnumbered the cell, making the real (larger) cell score as "oversized". Fix: pick the cell first as the **largest object present in ~every frame**, then derive expected area from it. |
| Pos10-WT | 2026-06-17 | **id2** is the target cell. **id1** is a large uniform optical shadow (artifact); the cell crosses onto it at **frame 83+** and takes the id1 label. **id3** is debris / a rounded cell passing through. | Drove two capabilities, both now in `core.single_cell_curation` (schema v2): (1) a **DIC texture score** (in-mask intensity std) that distinguishes a flat optical shadow (id1 ≈16) from a textured cell (id2 ≈33) — size/persistence alone can't; (2) **label-agnostic per-frame track assembly** that universally ID-stitches the one cell across label switches. The algorithm independently recovered the id2→id1 switch at **frame 83** and now auto-resolves this recording (presence 100%, no flag). |
| Pos33-GOF | 2026-06-17 | **id1** is the target cell. It **crumples to a ball (rounds up) at frames 36–40** then returns to flattened — a real morphological state, NOT a division and NOT a detection error. It must be **tracked through the rounded state with that state outlined**. | The small/round masks at 36–40 are correct and should be kept. Fixed the curation: **under-segmentation "repair" is now OFF by default**, and the per-frame pick judges size against the cell's *previous* size (continuity), so it follows the cell through rounding instead of dropping the small frames. Resolves with presence 1.0, no flag, rounded state outlined. (`repair_undersized` left as an opt-in param.) |
| Outline review (all 78) | 2026-06-17 | Reviewed every recording in the review GUI. **Cell identities all correct (1 cell/recording, present every frame).** Flagged 21 with imperfect outlines — mostly under-segmented (faint protrusions/tails clipped by noise), a few with a spurious noisy extension. | **Accepted masks as-is.** Guarded SAM2 refinement (`ic293_refine_flagged.py`, non-destructive `masks_refined.npz`) recovered only 20/1482 frames — the faint thin protrusions resist safe automatic refinement (anything aggressive enough to grab them also grabs noise). Decision: the clipping doesn't affect the **centroid-based motility metrics** (the primary readouts) and the area bias is consistent across conditions (cancels in between-treatment contrasts), so the curated masks stand. `masks_refined.npz` NOT promoted; manual brush remains available for figure-quality outlines if needed later. |
| Pos36_div-GOF | 2026-06-17 | An **actual dividing cell** — should not have been in the set (violates the non-dividing criterion). Pre-division window is only ~13 frames. | **Excluded from the statistical analysis** (file kept on disk, not deleted). 13 frames < the 30-frame minimum across the set (median 60) and < the 24-frame MSD window, so it can't contribute comparable motility metrics. Added to `ic293_common.ANALYSIS_EXCLUDE`; `ic293_track_data` + `ic293_compare` skip it. Auto-flagged by the curation via `frequent_label_switches` (6 switches = the division signature). Analysis set = **77** single-cell recordings, all ≥30 frames. |
